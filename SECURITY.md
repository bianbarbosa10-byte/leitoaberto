# Política de segurança

O LeitoAberto é um site estático com dados públicos e agregados do DATASUS e do IBGE. Ele não tem login, formulários
nem dados pessoais. Mesmo assim, se você encontrar uma vulnerabilidade, por favor relate de forma privada:

- **GitHub → aba Security → "Report a vulnerability"** (relato privado de vulnerabilidade está ativo neste repositório).

Não abra issue pública para falhas de segurança. Resposta em até 7 dias.

## Escopo

- Site: https://bianbarbosa10-byte.github.io/leitoaberto/
- Código deste repositório (pipeline, SQL, site e workflow do GitHub Actions)

Fora do escopo: os serviços de terceiros em si (GitHub, Cloudflare, Neon, DATASUS) e ataques de negação de serviço.
